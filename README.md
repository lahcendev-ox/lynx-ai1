# LYNX AI

واجهة محادثة ذكاء اصطناعي مبنية بـ Node.js وExpress وGoogle Gemini API.

## المزايا
- Gemini 3.8 Flash عبر الخادم.
- محادثات جديدة، فتح المحادثات السابقة، حذفها، ومتابعتها.
- حفظ منفصل لكل متصفح/جهاز باستخدام UUID في `localStorage`.
- حفظ كل محادثة في ملف JSON مستقل.
- رفع الصور وPDF والملفات النصية وCSV وJSON وبعض ملفات البرمجة.
- Markdown والجداول وكتل الأكواد.
- الوضع الداكن والفاتح وستة ألوان للواجهة.
- مفتاح Gemini لا يصل إلى المتصفح.

## التشغيل محلياً

1. ثبّت Node.js 20 أو أحدث.
2. افتح مجلد المشروع ثم نفّذ:

```bash
npm install
```

3. انسخ `.env.example` إلى `.env`، ثم ضع مفتاحك في `GEMINI_API_KEY`.
4. شغّل:

```bash
npm start
```

5. افتح `http://localhost:3000`.

## النشر على Render

1. ارفع ملفات المشروع إلى مستودع GitHub.
2. في Render اختر **New → Blueprint** واربط المستودع، أو أنشئ Web Service يدوياً.
3. أضف متغير البيئة `GEMINI_API_KEY` وضع مفتاح Google AI Studio.
4. استخدم:
   - Build Command: `npm install`
   - Start Command: `npm start`
5. يجب استخدام Persistent Disk. ملف `render.yaml` يجهز قرصاً على `/var/data` ويضبط `DATA_DIR=/var/data`.
6. بعد النشر افتح رابط الخدمة.

> تنبيه: إعداد القرص في Blueprint يستخدم خطة Render مدفوعة (Starter). لا تعتمد على نظام الملفات المؤقت في خدمة مجانية لحفظ محادثات دائمة؛ قد تختفي البيانات عند إعادة التشغيل أو إعادة النشر. خذ نسخاً احتياطية دورية من مجلد البيانات.

## ملاحظات مهمة حول الخصوصية والهوية

- معرّف المستخدم مرتبط ببيانات المتصفح (localStorage)، وليس إثبات هوية أو تسجيل دخول. إذا مسح المستخدم بيانات المتصفح أو انتقل إلى متصفح/جهاز آخر فسيحصل على معرّف جديد ولن يرى محادثاته القديمة تلقائياً.
- لا يمكن اعتبار هذا الأسلوب حماية قوية ضد انتحال الهوية؛ من يعرف معرّف المستخدم يستطيع نظرياً استخدامه. إذا أصبحت البيانات حساسة، أضف تسجيل دخول أو رمز استرداد.
- تعليمات النظام توجه سلوك النموذج لكنها ليست وسيلة تشفير أو ضماناً مطلقاً لإخفاء التعليمات عن كل محاولات التلاعب.
- يدعم هذا الإصدار صورة واحدة أو ملفاً واحداً في كل رسالة، وبحد افتراضي 15MB. أنواع الملفات المسموح بها محددة في `server.js`.
- الملفات تحفظ كنصوص/بيانات محادثة فقط؛ لا تُخزّن نسخة أصلية من الملف المرفق على القرص.

## متغيرات البيئة

| المتغير | الوظيفة |
|---|---|
| `GEMINI_API_KEY` | مفتاح Gemini API |
| `GEMINI_MODEL` | النموذج، افتراضياً `gemini-3.8-flash` |
| `DATA_DIR` | مجلد تخزين بيانات المستخدمين |
| `PORT` | منفذ الخادم |
| `MAX_FILE_MB` | أقصى حجم للمرفق بالميغابايت |
